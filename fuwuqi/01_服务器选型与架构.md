## 一、为什么选 ARM64 裸金属 + Waydroid

### 1.1 APK 为什么在 Windows 上失败

CarScanner APK（`com.companyname.cardemo`）包含 ARM64 原生库（Xamarin.Android AOT 编译产物、Syncfusion 等第三方 SDK 的 arm64-v8a .so 文件）。

| 环境 | 模拟器系统镜像 | ABI | APK 是否能跑 |
|------|--------------|-----|-------------|
| Windows Intel/AMD x86 | x86_64 | x86_64 | ✗ 启动闪退（ABI 不兼容） |
| macOS Apple Silicon (M系列) | arm64-v8a | arm64 | ✓ 正常 |
| Linux x86_64 服务器 + KVM | x86_64 | x86_64 | ✗ 同 Windows |
| **ARM64 裸金属服务器 + Waydroid** | **arm64-v8a** | **arm64** | **✓ 正常** |

结论：必须在 ARM64 宿主机上运行 ARM64 Android 环境，APK 才能正常工作。

### 1.2 为什么用 Waydroid 而不是 Android Emulator

| 方案 | 依赖 | 性能 | 无头支持 | 适合服务器 |
|------|------|------|---------|-----------|
| Android Emulator (QEMU) | KVM + X11 or noVNC | 中等 | 需额外配置 | 勉强 |
| **Waydroid** | Linux binder + lxc | **接近原生** | ✓ 内置 | **推荐** |
| Redroid (Docker) | KVM + binder | 好 | ✓ | 可选方案 |

Waydroid 优势：
- 直接使用宿主机 ARM64 内核，APK 无需翻译层
- 无头模式原生支持（不需要 X11/Wayland 窗口系统）
- ADB 完全支持，与本地开发体验一致
- 资源消耗远低于完整 QEMU 模拟器

### 1.3 阿里云裸金属实例推荐规格

> 普通 ECS 虚拟机（如 ecs.c7/g7）**不支持嵌套虚拟化**，Waydroid 无法运行。

**推荐型号**：`ecs.g8y` 系列（倚天 ARM64 神龙裸金属）

| 规格 | vCPU | 内存 | 月费（参考） | 备注 |
|------|------|------|------------|------|
| ecs.g8y.2xlarge | 8核 | 32GB | ~600元/月 | 单实例足够 |
| ecs.g8y.4xlarge | 16核 | 64GB | ~1200元/月 | 多实例扩容用 |

操作系统：**Ubuntu 22.04 LTS ARM64**（Waydroid 官方支持最好）

需开放的安全组端口：
- `22` TCP — SSH
- `8080` TCP — WebSocket 测试阶段（生产阶段关闭，改为443）
- `443` TCP — HTTPS/WSS（生产阶段）

### 2.2 生产阶段（wss://，Nginx TLS）

```
用户手机(B端)
    │
    │ wss://your-domain.com/ws
    ▼
服务器:443 (Nginx)
    │ TLS 终止
    │ proxy_pass ws://127.0.0.1:8080
    ▼
宿主机:8080
    │ adb forward
    ▼
Waydroid内:8080 (CarScanner APK WebSocket Server)
```

## 三、与本地开发环境的对比

| 项目 | 本地 Mac | 云服务器 |
|------|---------|---------|
| Android 容器 | Android Studio 模拟器 (Pixel 6 API 34) | Waydroid LXC 容器 |
| ADB 连接方式 | `adb -s emulator-5554` | `adb -s 192.168.240.112:5555` |
| APK 安装 | `adb install -r xxx.apk` | `adb -s 192.168.240.112:5555 install -r xxx.apk` |
| APK 重启 | `am force-stop` + `am start` | 同左，通过 SSH 执行 |
| B端连接地址 | `Mac局域网IP:8080` | `服务器公网IP:8080`（测试）/ `wss://域名/ws`（生产） |
| Metro 服务器 | `localhost:8081`（开发用） | **不需要**（生产 APK 已打包 JS） |

## 四、数据流

```
ELM327（OBD设备）
    ↕ 蓝牙（BLE / MFi / 经典BT）
B端手机 App
    ↕ WebSocket（ws:// 或 wss://）
服务器 (Nginx → Waydroid → APK)
    ↑ APK 内部解析 OBD 协议，生成诊断结果
    ↓ 通过 WebSocket 把结果（故障码/传感器数据/ECU信息）回传 B端
B端展示 React Native UI
```
