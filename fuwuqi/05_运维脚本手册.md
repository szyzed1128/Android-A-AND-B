# 05 运维脚本手册

> 所有脚本位于 `fuwuqi/scripts/` 目录。
> 运行位置见每个脚本的说明。

---

## 脚本速查

| 脚本 | 运行位置 | 何时使用 |
|------|---------|---------|
| `deploy_to_server.sh` | **本地 Mac** | 修改了 A端代码，需要更新服务器 |
| `server_setup_waydroid.sh` | **服务器** | 首次配置服务器（仅一次） |
| `server_start.sh` | **服务器** | 服务器重启后，或 Waydroid session 需要重启时 |
| `server_restart_apk.sh` | **服务器** | 只重启 APK（最常用，秒级） |
| `server_status.sh` | **服务器** | 查看各组件状态 |

---

## 一、deploy_to_server.sh（本地运行）

**用途**：构建 APK + scp 传输到服务器 + 远程安装 + 重启 APK，一键完成。

**运行位置**：本地 Mac

**用法**：
```bash
cd /Users/zed/Documents/Programe/CarUI/NewUI
bash fuwuqi/scripts/deploy_to_server.sh
```

**流程**：
1. 设置 JAVA_HOME（避免 apksigner 找不到 Java）
2. 运行 `build_and_inject.sh`（构建 WebSocket 层 + 注入 DLL）
3. 运行 `automator.py`（打包签名 APK）
4. scp 将 APK 传输到服务器 `/opt/cardemo/`
5. SSH 远程执行 `server_install_apk.sh`
6. SSH 远程执行 `server_restart_apk.sh`

**前提**：
- 已在脚本顶部配置 `SERVER_IP`、`SSH_KEY`
- 服务器上 Waydroid 已启动（`waydroid status` 显示 RUNNING）

---

## 二、server_setup_waydroid.sh（服务器运行）

**用途**：首次配置服务器，安装 Waydroid 及所有依赖。**仅运行一次**。

**运行位置**：服务器

**用法**：
```bash
sudo bash /opt/cardemo/scripts/server_setup_waydroid.sh
```

**执行内容**：
- 安装 adb、curl、lxc-utils
- 添加 Waydroid apt 源并安装 Waydroid
- 创建 systemd service（waydroid-session）
- 创建 `/opt/cardemo/scripts/` 目录并放置其他脚本
- 创建 `/opt/cardemo/backup/` 目录

---

## 三、server_start.sh（服务器运行）

**用途**：启动 Waydroid session + 等待 APK 启动 + 建立 adb forward。

**运行位置**：服务器

**用法**：
```bash
sudo bash /opt/cardemo/scripts/server_start.sh
```

**流程**：
1. 启动 Waydroid session（如果未运行）
2. 等待容器完全启动（最多 120 秒）
3. 连接 ADB
4. 启动 APK
5. 建立 adb forward tcp:8080 tcp:8080
6. 验证 WebSocket 端口可访问

**何时使用**：
- 服务器重启后
- Waydroid session 异常退出后
- 系统维护后

---

## 四、server_restart_apk.sh（服务器运行）

**用途**：仅重启 APK，不重启 Waydroid。秒级操作，最常用。

**运行位置**：服务器

**用法**：
```bash
bash /opt/cardemo/scripts/server_restart_apk.sh
```

**流程**：
1. `am force-stop com.companyname.cardemo`（强制停止）
2. 等待 2 秒
3. `am start -n com.companyname.cardemo/crc64b16463db6be126c1.MainActivity`
4. 等待 5 秒
5. 重新执行 `adb forward tcp:8080 tcp:8080`（确保端口映射有效）

**类比**：相当于在本地模拟器里"清掉后台再点击图标"。

## 六、常用命令速查（SSH 到服务器后）

> ⚠️ 实际部署中 ADB 通过 socat 代理，设备 ID 为 `localhost:5555`（不是 `192.168.240.112:5555`）

```bash
# 查看 APK 日志（全量）
adb -s localhost:5555 logcat | grep -E "OBDCloud|JSBridge|WebSocket"

# 查看 [FLOW] 全链路日志
adb -s localhost:5555 logcat -v time | awk '/\[FLOW\]/ { print; fflush(); }'

# 清除日志缓冲区后重新监听
adb -s localhost:5555 logcat -c && adb -s localhost:5555 logcat -v time | awk '/\[FLOW\]/ { print; fflush(); }'

# 重启 APK（最常用）
bash /opt/cardemo/restart_apk.sh

# 完整重启（服务器重启后）
bash /opt/cardemo/startup.sh

# 检查容器状态（替代 waydroid status）
lxc-info -n waydroid -P /var/lib/waydroid/lxc/

# 容器被冻结时解冻
lxc-unfreeze -n waydroid -P /var/lib/waydroid/lxc/

# 手动重建 adb forward（断开时用）
adb connect localhost:5555
adb -s localhost:5555 forward tcp:18080 tcp:8080

# 列出已安装的 APK
adb -s localhost:5555 shell pm list packages | grep cardemo

# 强制停止 APK
adb -s localhost:5555 shell am force-stop com.companyname.cardemo

# 启动 APK
adb -s localhost:5555 shell am start -n \
  com.companyname.cardemo/crc64b16463db6be126c1.MainActivity
```

**从本地 Mac SSH 执行（一行命令查日志）：**

```bash
# 清空日志
ssh -i ~/.ssh/aliyun_hangzhou.pem root@121.40.198.17 \
  'adb -s localhost:5555 logcat -c'

# 实时 FLOW 日志
ssh -i ~/.ssh/aliyun_hangzhou.pem root@121.40.198.17 \
  'adb -s localhost:5555 logcat -v time' \
  | awk '/\[FLOW\]/ { print; fflush(); }'

# 重启 APK
ssh -i ~/.ssh/aliyun_hangzhou.pem root@121.40.198.17 \
  'bash /opt/cardemo/restart_apk.sh'
```
