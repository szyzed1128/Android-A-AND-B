## 一、架构一句话概括

```
B端(手机) ──ws://:8080/ws──> 服务器Nginx(:8080) ──ws://127.0.0.1:18080──> adb forward(18080→8080) ──> socat+nsenter代理 ──> Waydroid容器 ──> APK监听:8080
```

> **实际部署说明（与原设计的主要差异）：**
> 1. ADB 无法直连容器 IP（netd 崩溃导致网络不通），改用 socat+nsenter 代理到 `localhost:5555`
> 2. `adb forward` 只绑定 127.0.0.1，所以必须加一层 Nginx 才能对外暴露
> 3. adb forward 内部端口改为 18080（避免与 Nginx 监听的 8080 端口冲突）
> 4. 启动需先运行 weston headless（提供真实 Wayland socket），否则 SurfaceFlinger 无法启动
> 5. 已 patch `hardware_manager.py` 禁用 suspend 冻结（否则容器会自动 FROZEN）

- **A端** = ARM64 裸金属服务器上的 Waydroid 容器，里面运行 CarScanner APK
- **B端** = 用户手机（Android/iOS），在 App 设置界面输入服务器域名/IP
- **Waydroid** 代替传统 Android Emulator，直接在 ARM64 Linux 内核上运行 AOSP 容器，无需 QEMU 模拟

## 四、本地环境与服务器环境的共存原则

- **本地不变**：`NewUI/yun/`、`NewUI/automator.py` 等所有现有文件完全不动
- **服务器配置独立**：所有服务器相关配置、脚本集中在 `NewUI/fuwuqi/scripts/`
- **APK 构建不变**：服务器部署复用本地现有构建流程，只是在 scp 阶段把 APK 传到远端
- **B端 App 不需要重新打包**：B端代码的 `cloudHost` 是运行时配置（用户在 App 内输入），切换本地/服务器只需修改 App 设置界面的值

## 六、端口全景（实际部署版本）

```
【本地 Mac 环境】
手机B端  ──ws://Mac局域网IP:8080/ws──▶  Mac:8080
                                          │ (adb forward tcp:8080 tcp:8080)
                                          ▼
                                   模拟器内APK:8080

【云服务器环境（当前测试阶段，ws://）】
手机B端  ──ws://121.40.198.17:8080/ws──▶  Nginx:8080 (0.0.0.0)
  B端输入：Host=121.40.198.17, Port=8080    │ proxy_pass http://127.0.0.1:18080
                                            ▼
                                     adb forward 127.0.0.1:18080→容器:8080
                                            │ (socat+nsenter 代理到 localhost:5555)
                                            ▼
                                     Waydroid容器内APK:8080

【云服务器环境（生产阶段，wss://）】
手机B端  ──wss://your-domain.com/ws──▶  Nginx:443
  B端输入：wss://your-domain.com          │ TLS termination + proxy_pass http://127.0.0.1:18080
                                          ▼
                                   adb forward 127.0.0.1:18080→容器:8080
                                          ▼
                                   Waydroid容器内APK:8080
```
